# Dayflow HRMS

Dayflow HRMS is a Human Resource Management System built on Odoo, designed to bring every workday into one aligned view. It extends Odoo's core HR framework (Employees, Attendance, Time Off) with a custom **Employee Dashboard** — a single screen that combines attendance status and leave summary for each employee, so managers don't need to jump across multiple screens to check on their team.

## Key Feature: Employee Dashboard
Our custom module (`dayflow_hr`) adds a dashboard that shows, for each employee:
- Today's attendance status (Present / Not Checked In)
- Number of pending leave requests
- Number of approved leaves for the month

This solves a real pain point in HR workflows — managers currently have to check Attendance and Time Off separately to get a full picture of an employee's status. Dayflow brings it into one place.

## Tech Stack
- **Odoo 18** (Python + XML ORM framework)
- **PostgreSQL** (database)
- **Docker** (local development environment)
